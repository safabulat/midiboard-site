Connecting to Windows

Windows does not accept Bluetooth MIDI into an application directly; it needs a bridge. The route that works, and the one Midiboard is built and tested against:

  1. In Midiboard, tap Connect. The name you set is what the PC will show.
  2. On the PC: Settings → Bluetooth & devices → Add device → Bluetooth, and pick that name.
  3. Open MIDIBerry and route the Midiboard input into a loopMIDI port.
  4. In your host — Gig Performer, Ableton, whatever it is — select that loopMIDI port as a MIDI input.

If the PC pairs but nothing arrives, MIDIBerry is nearly always the missing step: pairing in Windows settings makes the device known, not audible.

Connecting to macOS

No bridge needed. Audio MIDI Setup → Window → Show MIDI Studio → Bluetooth, find the name and press Connect. It then behaves like any other MIDI source.

Connecting to an iPad

Most iPad music apps have a Bluetooth MIDI panel of their own; open it and connect. Apps that use Apple's standard sheet will list Midiboard by name.

It says the link was lost

That message means the app is still holding a connection that has stopped accepting anything — usually a laptop that went to sleep, or a walk out of range. Midiboard drops it and starts advertising again by itself; Retry forces that immediately. If the other machine had gone to sleep, wake it and re-connect from its side.

A note is stuck

Panic in the control strip. It clears the app's own note state first and then tells the receiver to silence everything — in that order, because doing it the other way round lets a monophonic widget helpfully retrigger the note underneath as you lift your finger.

Something in my host learned the wrong control

Use the Learn buttons in the widget inspector rather than moving the control by hand. A learn sends that one control on its own and mutes everything else the app would send for the duration, so the receiving end has nothing else to latch onto. An XY pad gets a button per axis, which is the case that most needs it — both axes move the instant you touch the pad.

Locking the screen during a gig

Nothing playable sits in the home-indicator strip, so an accidental brush at the bottom no longer reveals it. iOS will not let any app disable the swipe-up gesture outright, though. For a performance where nothing may go wrong, use Settings → Accessibility → Guided Access; it is the only true lock the system offers.

Reporting a bug

Write to safabulatdev@icloud.com. What helps most: your iOS version, what the other end of the chain is, and what you were doing when it happened — "it did it while I was transposing with a pad held" is worth more than a screenshot.
