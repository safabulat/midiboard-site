Bluetooth MIDI on Windows

Use your iPhone as a wireless MIDI controller for Gig Performer, Ableton Live, FL Studio, Reaper or any other Windows music software. Five minutes, two free utilities, no cables.

Why Windows needs two extra pieces

A Mac or an iPad accepts a Bluetooth MIDI device directly. Windows pairs one, but does not hand it to music software as an ordinary MIDI input — so after pairing, the DAW still sees nothing. Two small free utilities close that gap:

  • MIDIberry (Microsoft Store) reads the Bluetooth MIDI device through Windows' own Bluetooth MIDI support and forwards it.
  • loopMIDI (by Tobias Erichsen) creates a virtual MIDI port: MIDIberry writes into it, and your DAW reads from it like a cable.

The chain, once it is set up: iPhone → Bluetooth → MIDIberry → loopMIDI port → your DAW.

Set it up

  1. Install both utilities. MIDIberry from the Microsoft Store; loopMIDI from tobias-erichsen.de.
  2. Create a virtual port. Open loopMIDI, type a name such as Midiboard Port, press +. Leave loopMIDI running; it sits in the tray.
  3. Pair the phone. In Midiboard tap Connect — the name shown there is what Windows will list. On the PC: Settings → Bluetooth & devices → Add device → Bluetooth, and pick it.
  4. Bridge it. Open MIDIberry. Input: the phone's name. Output: Midiboard Port. Touch a pad on the phone — MIDIberry shows the notes arriving. Keep MIDIberry open: it is the bridge, and closing it stops the notes.
  5. Select the port in your software. Enable Midiboard Port as a MIDI input — not the phone's Bluetooth name, which the DAW either does not list or cannot open.
    • Gig Performer: Options → MIDI Ports, tick the port as an input; then MIDI-learn widgets as usual.
    • Ableton Live: Settings → Link, Tempo & MIDI, set the port's Track (and Remote, for mapping) to On.
    • FL Studio: Options → MIDI settings, enable the port in the Input list.
    • Reaper: Preferences → Audio → MIDI Inputs, enable the port.

If nothing arrives

  • The phone is paired but MIDIberry does not list it. Open Midiboard first and make sure it says it is waiting for a connection, then restart MIDIberry. If it still is not there, remove the device in Windows Bluetooth settings and pair it again.
  • MIDIberry shows notes, the DAW does not. The DAW is listening to the wrong port — select the loopMIDI port, and check the DAW was opened after the port was created (most only scan at launch).
  • It worked and then went silent. A PC going to sleep drops the Bluetooth link. Reconnect from MIDIberry; in Midiboard, the connection light tells you whether the phone still thinks it is connected.
  • A note is stuck. Midiboard's panic button sends All Notes Off on every channel.

Newer Windows 11

Microsoft is building MIDI support into Windows 11 (Windows MIDI Services), including virtual ports of its own. Where your version already offers those, one can stand in for loopMIDI; the Bluetooth bridge step is still needed for now. The setup above works on Windows 10 and Windows 11.

Rather not use Bluetooth?

Midiboard can also connect over Wi-Fi as an RTP-MIDI session — see Support → Connecting over Wi-Fi. Bluetooth is usually the simpler of the two on stage: no network to depend on.
